# Field calls — xếp hạng pain P2 / P3 / P4 (ADR-018 W2-5)

> **Owner:** Minh An / bạn · **Không phải code** · Mục tiêu Sense trước khi mở Lớp 3  
> **Cỡ mẫu gợi ý:** 5–10 chủ nhà / đối tác đang hoặc sắp cho thuê

## Mục tiêu

Xác nhận pain nào đang «đốt tiền / thời gian» thật sự:

| Pain | Giả thuyết |
|------|------------|
| **P2** | Khó tìm khách / trống phòng lâu → cần Lớp 2 hoa hồng |
| **P3** | Sợ thuế / không biết dòng tiền ròng → tool + referral KT |
| **P4** | Muốn người quản lý căn → **chỉ Sense**; chưa bán QL |

## Script ngắn (10–15 phút)

1. Bạn đang cho thuê bao nhiêu căn / loại nào?  
2. Khó nhất hiện tại: tìm khách, thuế, hay vận hành hàng ngày? (chỉ chọn 1 ưu tiên)  
3. Thời gian trống phòng trung bình lần gần nhất?  
4. Bạn có dùng kế toán / tự kê khai không?  
5. Nếu có dịch vụ «chỉ tìm khách + hoa hồng» vs «QL thu tiền + bảo trì» — bạn chọn cái nào *trong 12 tháng tới*?  
6. Ghi `painPrimary`: P2 | P3 | P4 (+ ghi chú 1 câu).
